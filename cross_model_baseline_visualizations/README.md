# Cross-model baseline — visualizations

Per-round trajectories for the **cross-model baseline** (a MAIN model reads documents
synthesized from a SIDE model's answers; the MAIN model is measured). Generated by
[`../cross-model-baseline-visualization.ipynb`](../cross-model-baseline-visualization.ipynb).
Overlaid line charts in `visualization.ipynb` style (Replace All `#1f77b4` / Replace One `#ff7f0e`).

## Text metrics (from `evaluation.py`)

From `scripts/cross_model_baseline/eval_cross_model_baseline.sh` (no entity dependency), one metric
averaged across questions per round:

- `avg_pairwise_similarity_per_round.png` — cosine similarity across the 10 runs
- `avg_pairwise_rougeL_per_round.png` — ROUGE-L across runs
- `avg_pairwise_tes_per_round.png` — token-edit similarity
- `same_answer_percentage_per_round.png` — same-answer % (Qwen2.5-7B judge)
- `unique_words_per_round.png` — unique words (round union)
- `ai_reference_percentage_per_round.png` — AI-reference %
- `all_metrics_per_round.png` — combined grid

## Entity metrics (from the GPT-5.2 entity re-run dump)

Recomputed from the per-question `*.entities_by_round.jsonl` **cross-model** files (Qwen main model)
in the latest `entity re-run for workshop paper-*` dump (auto-discovered by regex), matching
`entity_extraction.py` / `visualization.ipynb`:

- `unique_entities_per_round.png` — union of canonical entities across the 10 runs, averaged over questions
- `entity_similarity_per_round.png` — mean pairwise cosine similarity of binary entity-mention vectors
- `collapse_by_simulation.png` — % of question-rounds where all 10 runs share one entity set;
  error bars are **95% Wilson CIs**

## Regenerating

1. Download the per-variant eval JSONs from Unity into `../cross-model-baseline/evaluation_outputs/`
   (gitignored): `local_<variant>_eval.json` — needed for the text-metric charts.
2. Unzip the entity re-run dump into the repo root as `entity re-run for workshop paper-<ts>/`
   (command line, not Explorer — see `CLAUDE.md`) — needed for the entity charts. The cross-model
   files are `model_collapse_log_graphite_cross_model_<variant>_Qwen_Qwen2.5-14B-Instruct_local_<variant>.entities_by_round.jsonl`.
3. Run all cells of `../cross-model-baseline-visualization.ipynb`.

**Extensible:** the text-metric loader's `VARIANTS` map lists `replace_all` / `replace_one` / `search`
and skips eval files not present; the entity section reads whichever cross-model files exist in the dump
(currently Replace All + Replace One). When `search` is added, both join the plots automatically.
