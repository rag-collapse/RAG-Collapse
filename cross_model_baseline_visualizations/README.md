# Cross-model baseline — text-metric visualizations

Per-round text-similarity trajectories for the **cross-model baseline** (a MAIN model reads documents
synthesized from a SIDE model's answers; the MAIN model is measured). Generated by
[`../cross-model-baseline-visualization.ipynb`](../cross-model-baseline-visualization.ipynb).

**Text metrics only — no entity metrics.** These come from `evaluation.py` (`scripts/cross_model_baseline/eval_cross_model_baseline.sh`),
which has no entity dependency. `unique_entities` / `entity_similarity` / collapse-by-simulation are
entity-based and intentionally excluded.

Each PNG overlays the available variants, one metric averaged across questions per round (shaded =
standard error of the mean):

- `avg_pairwise_similarity_per_round.png` — cosine similarity across the 10 runs
- `avg_pairwise_rougeL_per_round.png` — ROUGE-L across runs
- `avg_pairwise_tes_per_round.png` — token-edit similarity
- `same_answer_percentage_per_round.png` — same-answer % (Qwen2.5-7B judge)
- `unique_words_per_round.png` — unique words (round union)
- `ai_reference_percentage_per_round.png` — AI-reference %
- `all_metrics_per_round.png` — combined grid

## Regenerating

1. Download the per-variant eval JSONs from Unity into `../cross-model-baseline/evaluation_outputs/`
   (folder is gitignored): `local_<variant>_eval.json`.
2. Run all cells of `../cross-model-baseline-visualization.ipynb`.

**Extensible:** the notebook's `VARIANTS` map lists `replace_all` / `replace_one` / `search`; the loader
skips any eval file not present. When `replace_one` (or `search`) finishes and is downloaded, just
re-run — it joins every plot automatically.
