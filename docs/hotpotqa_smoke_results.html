What this page is, in plain terms

RAG (retrieval-augmented generation) just means a language model answers a question by first pulling in some documents and reading them. “RAG collapse,” the thing this project studies, is what happens when you close the loop: take the model’s own answer, turn it back into a “document,” feed it in as context next round, and repeat. Over many rounds the answers tend to degenerate — they lose variety and/or drift away from the truth. This happens at answer time, with no retraining.

The recursive loop, one round at a time:

retrieve top documents→ model answers→ answer condensed into a new “document”→ fed back as context↻ repeat 10–30 rounds

HotpotQA is the question set used here: multi-hop questions (each needs facts from two or more Wikipedia paragraphs) that have a short, exact “gold” answer — so we can measure whether the model still gets it right as the loop runs.

The five runs below ask: does planting a false claim inside the loop make the error compound over rounds (runs 01–03)? does a byte-level text fix for one model hold up at scale (run 04)? and can we reproduce the original HotpotQA paper’s “distractor” setting — real but misleading documents mixed in at the start — inside the loop (run 05)?

Read these as smoke tests. They use tiny question sets to check the machinery runs and the numbers move in sensible directions — not as final results. Every term is defined in the glossary at the bottom.

03 / SYNTHETIC DISTRACTOR — FIX

Gold-leak removed, every doc now a real distractor

What this is: the fix for run 02. It discards any “distractor” that accidentally repeats the correct answer (gold-leak) and, when the rewrite fails, swaps in a clean wrong entity instead — so every corrupted document now carries a real, distinct falsehood.

— / STATUS & CAVEATS

What's validated, what's pending

  • Injection machinery, distractor seeding, the Q1 fix, the byte-decode, and native distractor-setting seeding all run end-to-end and clean.
  • The faithful native setting (replace_one) is confirmed across all four answer models — Qwen2.5-14B, Mistral-7B, Llama-3.1-8B, DeepSeek-R1-7B: round 0 = 10 docs (2 gold + 8 distractor), gold-only = 2 gold, all clean.
  • All HotpotQA numbers are preliminary smokes (20 q, num_runs 2–10) — magnitudes are not yet statistically meaningful.
  • hybrid truncates the 10-paragraph native context — use replace_one for the paper's setting.
  • The CMU host for the distractor file is dead — it's now reconstructed from HuggingFace automatically.

Ready next: the Qwen2.5-14B native full run (replace_one, 400 q, num_runs 10, distractor + gold-only) for statistically meaningful numbers.

— / GLOSSARY

Every term on this page, in one line

RAG
Retrieval-augmented generation — the model answers using documents it retrieves first.
recursive / self-refinement loop
Feeding the model's own answers back in as documents, round after round.
collapse
Answers degenerating over rounds — losing variety, or drifting off the truth.
HotpotQA
A multi-hop question-answering benchmark; each question has a short gold answer.
multi-hop
A question that needs facts combined from two or more documents.
gold answer / supporting facts
The correct short answer, and the specific paragraphs that justify it.
distractor (paper)
A real Wikipedia paragraph retrieved as a hard negative — related but does NOT contain the answer.
distractor (synthetic)
A retrieved doc we deliberately corrupt to assert a specific WRONG answer.
search / replace_one / hybrid
The three loop variants — growing store (30 rounds) / swap one doc per round (20) / replace the whole context (10).
round / iteration
One pass through the loop.
num_runs
How many independent answer samples are drawn per question per round.
faithful / counterfactual / freeform
Synthesis modes — write the truth / swap in a wrong entity / invent a plausible false claim.
injection
Planting a false claim into the document the model generates.
inject-round
The round whose generated document gets the planted error.
ASR (injected_match_rate)
Attack success rate — how often the model's answer adopts the planted wrong answer.
gold_match
How often the answer matches the correct gold answer (i.e. accuracy).
distractor_adoption_rate
How often the answer adopts any seeded distractor's wrong answer.
distinct_answers
How many different answers appear per question — a diversity measure.
offtarget_rate
How often the answer is neither the gold nor a seeded wrong answer.
gold-leak
A "distractor" that accidentally still asserts the correct answer — a failed distractor.
substitution fallback
When a rewrite fails to produce a wrong answer, swapping in a clean distinct wrong entity instead.
eligible
A question that qualifies for the manipulation (e.g. not a yes/no answer, gold present).
byte-artifacts (Ġ/Ċ)
Garbled tokenizer output (Ġ = space, Ċ = newline) when text isn't decoded properly.
F1 / EM
Standard QA scores — token overlap with the gold answer / exact match.
baseline
A plain reference run with no manipulation, to compare other runs against.
