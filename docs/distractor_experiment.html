HotpotQA · recursive RAG · error compounding

One wrong fact,
fed back to itself.

A recursive RAG loop turns its own answers into documents and re-reads them. This experiment plants a single plausible falsehood in one synthesized document and watches whether the model converges on the gold answer or drifts toward the injected error — round after round.

faithful answer / gold injected misinformation the loop laundered the error into a retrievable doc

01 / THE BASELINE LOOP

The original HotpotQA recursive-RAG loop

Every round runs the same four steps. Nothing is corrupted here — this is the machinery the experiment is built on.

retrieve top-k=10→ model answers from context→ answer condensed into a doc→ doc re-enters context↺
30 ROUNDS
search

A growing vector store. Each round retrieves the top-k again, so synthetic docs compete with the corpus for retrieval.

20 ROUNDS
replace_one

One document slot is swapped for a freshly synthesized doc each round; the rest of the context carries over.

10 ROUNDS
hybrid / replace_all

The entire context is replaced by documents synthesized from the prior round's answers.

The confound this fixes. By default the synthesizer writes a faithful condensation of the correct answer. That hands later rounds the answer pre-assembled — making questions easier and masking degradation (noted in the paper's Limitations). The overlay below replaces that faithful step with a controllable falsehood.

02 / THE OVERLAY

Injecting misinformation into the synthesis step

Instead of always condensing the correct answer, the synthesizer can plant one plausible false claim in the document it writes. Once that doc is re-retrieved, the experiment tracks whether the seeded error propagates, amplifies, or is corrected.

Not the same as collapse. This is a distinct construct from the project's diversity "collapse." It measures convergence toward a wrong attractor — the spread of a falsehood — not loss of lexical variety. Keep the two stories separate.

03 / SYNTHESIS MODES

How the document gets corrupted

Set by --doc-synthesis-mode. The faithful arm is a byte-identical control; the two treatments differ only in factual correctness.

Running example — "What is the capital of the state where Brown University is located?"  gold = Providence, bridge = Rhode Island.

04 / DISTRACTOR TARGETS

What part of the chain gets hit

Set by --target-mode. Picks where the falsehood lands in a multi-hop question.

05 / INJECTION TIMING

When the poison enters context

A document synthesized at the end of round it first enters context at round it+1. Pick an --inject-round and watch the contamination front move.

--inject-round
default = 1
